# Contributing

Thanks for using the ZIA Toolkit.

## Report a bug or request a feature

Please open an [issue](../../issues/new/choose). That is the way to get a fix or a change into this project.

A good bug report includes:

- What you did, what you expected, and what happened instead
- The error message shown in the portal or the terminal
- Your operating system and Python version (`python3 --version`)
- Whether the OneAPI category lookup was turned on
- The column names in your Web Insights export (the header row only)

## Keep private data out of issues

Issues on this repository are public. Do not attach or paste:

- Web Insights exports or output files (they contain hostnames, and exports contain user names)
- Client IDs, client secrets, tokens, or `.env` files
- Tenant names, vanity domains, or internal hostnames

If a bug only shows up with real data, describe the pattern (for example "a URL column with IPv6 addresses") or
build a small made-up file that reproduces it.

## Pull requests

This project does not accept outside pull requests. Changes are made and published by the maintainer. If you have
a fix in mind, describe it in an issue and include the relevant snippet there.

## Security problems

Do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting on the
repository's Security tab if it is available, or contact the maintainer directly.
