Getting startedThree steps, about five minutes
  1. Connect Zscaler once. Type your OneAPI client below (vanity domain, client ID, secret), or put it in a .env file and restart. Every tool uses it. You can skip this and still categorize from the logs alone.
  2. Add your exports once. In ZIA go to Analytics › Web Insights › Logs, pick the time range and filters, turn on the URL, category and rule columns, and export to CSV. Add the file(s) to the library below. For Block impact, filter the export to Policy Action = Allowed.
  3. Pick a tool. Web Insights de-duplicates by host and adds categories, apps, rules and SSL status. Block impact shows which allowed traffic a planned category block would break.
